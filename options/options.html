Peacedone Recorder

I take notes for you: the live captions of Google Meet, Microsoft Teams web and Zoom web become a transcript in the folder you choose. Nothing leaves this computer — no network requests.

Transcript folder

You choose the folder in the popup for every call (recent folders are remembered). Chrome can't write outside Downloads by itself, so a tiny local helper writes the files — it only puts .md/.json into the folder you chose and never touches the network.

Folder helper
Checking…

Each call: YYYY-MM-DD_HHMM_<platform>_<tag>.md — the readable transcript — plus raw/…json (raw lines for tools). If the folder can't be written, both go to Downloads/Peacedone/.

Recording

Auto-captions only clicks a control that clearly says it turns captions on (Meet: CC; Teams: More → Language and speech → Turn on live captions; Zoom: CC). If it can't, the warning “Captions are off” stays on the page — without captions there is nothing to record.

Before the call

  • Join from the browser. The desktop Zoom and Teams apps are invisible to the extension.
  • Turn on captions: Meet — CC button (or C); Teams — More (···) → Language and speech → Turn on live captions; Zoom web — CC / Show Captions, open “View full transcript” for speaker names.
  • Set the caption language to the language of the call.
  • Tell the others you keep a transcript from the live captions for your notes.

Peacedone Recorder

Takes notes on your calls from the live captions — saved as a file on your computer.

Ведёт заметки на созвонах по живым субтитрам и сохраняет их файлом на вашем компьютере.

Install — 2 minutes

  1. Unzip the archive and move the Peacedone-Recorder folder somewhere permanent, e.g. Documents. Chrome loads the extension from this folder — don't delete it later.
  2. In Chrome open chrome://extensions (paste it into the address bar).
  3. Switch on Developer mode — the toggle in the top-right corner.
  4. Click Load unpacked and select the Peacedone-Recorder folder (the one that contains manifest.json).
  5. Pin it: click the puzzle icon 🧩 next to the address bar → pin Peacedone Recorder. The red fluffy Peacedone appears in the toolbar.

Works in Chrome, Edge and Brave on Windows. If Chrome shows “Disable developer mode extensions”, just close that message.

Record a call

  1. Join the call in the browser: Google Meet, Microsoft Teams (web) or Zoom (web client). Desktop Zoom/Teams apps are invisible to extensions — choose “Join from your browser”.
  2. Peacedone pops up on the call page: Record this call? Pick the 🌐 language of the call and press ● Start recording. (Or click Peacedone in the toolbar → ● Start.)
  3. Captions and their language are switched on automatically. While recording, Peacedone writes in his notepad.
  4. Leave the call or press ■ Stop — the transcript is saved.
Why the language matters: captions only recognise the language set in the call. If people speak Russian while the call is set to English, the text turns into nonsense. Peacedone switches the call's caption language to the one you choose, and warns you if the captions look like the wrong language.

Where the files go

  • By default: Downloads › Peacedone. Each call is one readable file YYYY-MM-DD_HHMM_platform_company.md (plus raw data in raw/).
  • Any folder you like: click 📁 Choose folder. The first time Peacedone offers a one-time Install helper — a tiny setup file (about 10 seconds, no admin rights). If Chrome or Windows asks, choose Keep / Run. Then the normal Windows folder dialog opens.

Please note

Tell the other people on the call that you keep notes from the live captions — e.g. “Just so you know, I keep notes from the live captions.” In many countries recording or transcribing without consent is not allowed. Transcripts stay on your computer; don't share them without the participants' consent.
  • No audio is recorded and nothing is sent anywhere — the extension makes no network requests.
  • Captions are machine speech recognition: names, numbers and terms can be misheard.

Remove

  • Extension: chrome://extensions → Peacedone Recorder → Remove.
  • Folder helper (if installed): delete the folder %LOCALAPPDATA%\Peacedone and run in a command prompt:
    reg delete "HKCU\Software\Google\Chrome\NativeMessagingHosts\com.peacedone.recorder" /f

Установка — 2 минуты

  1. Распакуйте архив и положите папку Peacedone-Recorder в постоянное место, например в Документы. Chrome загружает расширение из этой папки — потом её не удаляйте.
  2. Откройте в Chrome адрес chrome://extensions (вставьте его в адресную строку).
  3. Включите Режим разработчика — переключатель в правом верхнем углу.
  4. Нажмите Загрузить распакованное и выберите папку Peacedone-Recorder (ту, где лежит manifest.json).
  5. Закрепите: значок пазла 🧩 рядом с адресной строкой → булавка у Peacedone Recorder. На панели появится красный пушистый Peacedone.

Работает в Chrome, Edge и Brave на Windows. Если Chrome покажет «Отключите расширения в режиме разработчика» — просто закройте сообщение.

Как записать звонок

  1. Зайдите на звонок через браузер: Google Meet, Microsoft Teams (веб) или Zoom (веб-клиент). Приложения Zoom/Teams для компьютера расширение не видит — выберите «Join from your browser».
  2. На странице звонка всплывёт Peacedone: Record this call? Выберите 🌐 язык звонка и нажмите ● Start recording. (Или значок Peacedone на панели → ● Start.)
  3. Субтитры и их язык включатся сами. Пока идёт запись, Peacedone пишет в блокнот.
  4. Выйдите из звонка или нажмите ■ Stop — транскрипт сохранится.
Почему важен язык: субтитры распознают только язык, выставленный в звонке. Если говорят по-русски, а в звонке стоит английский, текст превращается в бессмыслицу. Peacedone сам переключает язык субтитров на выбранный вами и предупредит, если субтитры похожи на другой язык.

Куда сохраняются файлы

  • По умолчанию: Загрузки › Peacedone. Каждый звонок — один читаемый файл ГГГГ-ММ-ДД_ЧЧММ_платформа_компания.md (сырые данные — в raw/).
  • В любую папку: нажмите 📁 Choose folder. В первый раз Peacedone предложит Install helper — маленький установщик на ~10 секунд, без прав администратора. Если Chrome или Windows спросят — «Сохранить» / «Выполнить». Потом откроется обычное окно выбора папки Windows.

Важно

Предупредите собеседников, что ведёте заметки по субтитрам — например: «Чтобы вы знали, я веду заметки по субтитрам». Во многих странах запись или расшифровка без согласия запрещена. Транскрипты остаются на вашем компьютере — не пересылайте их без согласия участников.
  • Звук не записывается, ничего никуда не отправляется — расширение не делает сетевых запросов.
  • Субтитры — машинное распознавание речи: имена, цифры и термины могут быть услышаны неверно.

Удаление

  • Расширение: chrome://extensions → Peacedone Recorder → Удалить.
  • Помощник папок (если ставили): удалите папку %LOCALAPPDATA%\Peacedone и выполните в командной строке:
    reg delete "HKCU\Software\Google\Chrome\NativeMessagingHosts\com.peacedone.recorder" /f
